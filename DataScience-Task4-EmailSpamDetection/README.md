# Email Spam Detection 📧
**Oasis Infobyte Data Science Internship - Task 4**

## Project Overview
This project features a Natural Language Processing (NLP) binary classifier designed to analyze the text of emails and accurately distinguish spam messages from legitimate (ham) messages.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, TF-IDF Vectorizer
* **Environment:** Jupyter Notebook

## Key Results
* Processed text data by handling capitalization, stopwords, and punctuation.
* Extracted numerical features from the raw text using a TF-IDF Vectorizer.
* Trained Multinomial Naive Bayes and Logistic Regression models.
* The Naive Bayes model achieved over 98% accuracy and precision, prioritizing high recall to ensure spam is effectively filtered.
