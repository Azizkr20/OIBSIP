# Iris Flower Classification 🌸
**Oasis Infobyte Data Science Internship - Task 1**

## Project Overview
This project is a machine learning classification model trained to identify the species of an Iris flower (Setosa, Versicolor, or Virginica) based on its physical measurements. 

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

## Key Results
* Performed Exploratory Data Analysis (EDA) and visualized feature distributions.
* Trained both Logistic Regression and Random Forest classifiers.
* Achieved 100% accuracy, ultimately selecting Logistic Regression for its computational efficiency on clean datasets.
