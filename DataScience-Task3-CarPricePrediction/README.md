# Car Price Prediction 🚗
**Oasis Infobyte Data Science Internship - Task 3**

## Project Overview
This project is a machine learning regression model built to predict the selling price of used cars based on historical vehicle data, including age, mileage, fuel type, and transmission.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

## Key Results
* Cleaned raw data and engineered new predictive features (`Car_Age` and `Brand`).
* Standardized categorical variables using One-Hot Encoding.
* Trained Linear Regression and Random Forest Regressor models.
* Linear Regression emerged as the best-performing model, achieving the highest R² score and lowest error rates.
